# odin-todo-list
The Odin Project Full Stack JavaScript: Todo List

A project and task management application built with JavaScript, HTML, and CSS as part of The Odin Project.

Organize your tasks into projects, manage deadlines, set priorities, and keep track of completed work.

Live Demo

View Todo List

Features

Project Management

Create and delete projects.

Switch between projects to view their associated tasks.

A default project ensures tasks always belong to a project.

Todo Management

Create, edit, and delete todos.

Add task titles, descriptions, and due dates.

Assign priorities: low, medium, and high.

Mark tasks as complete.

Data Persistence

Projects and todos are saved using browser localStorage.

Your data remains available when you revisit the application in the same browser.

Getting Started

To run the project locally:

1. Clone the repository

git clone git@github.com:TumiTarantino/odin-todo-list.git

2. Navigate into the project

cd odin-todo-list

3. Install dependencies

npm install

4. Start the development server

npm start

Open the local URL provided by Webpack Dev Server.

Building and Deployment

Build the production version:

npm run build

Deploy to GitHub Pages:

npm run deploy
